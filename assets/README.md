# Assets the school must supply

Place these files here. Every page already references them with relative paths and shows a navy and gold placeholder until they exist.

| File | Purpose | Notes |
|---|---|---|
| `assets/logo.png` | Header logo and favicon | **Included**, cropped from the school’s own Facebook logo (small, 320 px). Replace it with the official high-resolution PNG when you have it. Keep the same file name. |
| `assets/og.jpg` | Link preview image | **Included** (generated from the logo). Replace with a nicer photo-based image later. |
| `assets/photos/hero.jpg` | Home hero | 1200 x 900 px, under 200 KB. |
| `assets/photos/story.jpg`, `academics.jpg`, `sport.jpg`, `arts.jpg`, `boarding.jpg` | Section photos | 800 x 600 px, under 150 KB each. |
| `assets/photos/founder.jpg` | Founder portrait | 600 x 800 px. Needs permission to use. |
| `assets/photos/campus-<campusId>.jpg` | Campus card photo | 800 x 600 px. `<campusId>` is the campus document id, e.g. `campus-waverly.jpg`. |

Compress photos before uploading (JPEG, quality about 70) so pages load fast on weak data.
